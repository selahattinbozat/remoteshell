Frequently asked questions

Which key formats are supported?

OpenSSH private keys (Ed25519, ECDSA, RSA, encrypted or not) and PEM/PKCS#8 keys. PuTTY .ppk keys must first be converted in PuTTYgen (Conversions → Export OpenSSH key). Legacy encrypted PEM keys can be converted with ssh-keygen -p -f yourkey.

Why do I see "Host authenticity cannot be established"?

This appears the first time you connect to a server. Compare the fingerprint with the one on your server (ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub) before trusting it.

What does "REMOTE HOST IDENTIFICATION HAS CHANGED" mean?

The server presented a different key than the one you trusted before. This can happen after reinstalling a server, but it can also indicate an attack. Only accept the new key if you know why it changed.

Why did my session disconnect in the background?

iOS suspends apps shortly after they leave the screen. With "Keep Session Alive" enabled, RemoteShell uses the background time iOS allows and reconnects automatically when you return.

Is VNC encrypted?

Plain VNC is not encrypted. Enable "Tunnel Through SSH" in the server settings so VNC traffic runs inside an encrypted SSH connection.

How do I connect to a Windows PC with RDP?

Enable RDP in the server's settings, enter the Windows user name (and domain if needed), and connect. RemoteShell uses TLS and Network Level Authentication and shows the PC's certificate on the first connection. To reach a PC behind a firewall, turn on "Tunnel Through SSH".

Can I use two-factor authentication?

Yes. When your server asks for a one-time code (keyboard-interactive authentication), RemoteShell shows the question after your password or key was accepted. Codes are never saved.

How do I keep programs running when I leave the app?

Turn on "Persistent Session (tmux)" in the server's settings. Your shell then runs inside tmux on the server, keeps running while RemoteShell is in the background, and is re-attached when you return.

How do I use Mac Screen Sharing?

Enable Screen Sharing on the Mac, add the Mac with VNC enabled, and enter your macOS user name in the VNC section. RemoteShell signs in with your macOS account (Apple Remote Desktop authentication).
